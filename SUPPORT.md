# Support

- Installation and usage questions: [GitHub Discussions](https://github.com/RubsNeto/rn-mail-theme/discussions)
- Reproducible defects: [GitHub Issues](https://github.com/RubsNeto/rn-mail-theme/issues)
- Security vulnerabilities: private reporting described in [SECURITY.md](SECURITY.md)

Include the theme version, mailcow version, browser, relevant sanitized logs and reproduction steps. Never post credentials, private domains, email addresses, message contents or customer data.

RN Mail Theme is community-maintained and is not an official mailcow or SOGo product.
